# 디스코드 음성채널 입퇴장 알림 + 노래 재생 봇

음성채널에 누군가 들어오거나 나가면 음성(TTS)으로 안내하고, `/재생` 명령어로 유튜브 노래도 재생하는 봇입니다.

## 1. 디스코드 봇 생성하기

1. https://discord.com/developers/applications 접속 후 로그인
2. "New Application" 클릭 → 이름 입력
3. 왼쪽 메뉴에서 **Bot** 클릭 → "Add Bot"
4. **TOKEN** 항목에서 "Reset Token" → 토큰 복사 (외부에 절대 노출 금지)
5. 왼쪽 메뉴 **OAuth2 → URL Generator**
   - SCOPES: `bot`, `applications.commands` (슬래시 명령어 사용에 필수)
   - BOT PERMISSIONS: `View Channels`, `Connect`, `Speak`
6. 생성된 URL로 접속해서 봇을 원하는 서버에 초대

## 2. 로컬 환경 설정

Node.js 18 이상이 필요합니다.

```bash
npm install
cp .env.example .env
```

`.env` 파일을 열어 `DISCORD_TOKEN`에 토큰을 붙여넣으세요.

## 3. 실행

```bash
npm start
```

콘솔에 `✅ 로그인 완료`가 뜨면 정상 작동 중입니다.

## 슬래시 명령어

**설정 (서버 관리 권한 필요)**
- `/목소리 설정:남자` 또는 `설정:여자` — 안내 음성 목소리 변경
- `/속도 퍼센트:25` — 말하기 속도 변경 (-50~100)
- `/설정확인` — 현재 설정 확인

> 주의: 설정은 메모리에만 저장되어 봇이 재시작되면 기본값(남자, +25%)으로 초기화됩니다.

**음악 (누구나 사용 가능)**
- `/재생 검색어:노래 제목 또는 유튜브 링크`
- `/스킵`, `/정지`, `/일시정지`, `/재개`, `/대기열`

## 노래 재생 구조 (Lavalink)

노래 재생은 [Lavalink](https://github.com/lavalink-devs/Lavalink)라는, 대형 음악봇들도 쓰는 전용 오디오 서버 방식을 사용합니다. 유튜브 쪽에서 직접 오디오를 뽑아오는 대신, Lavalink 서버가 그 일을 대신 해주기 때문에 유튜브의 지속적인 정책 변경에 훨씬 안정적으로 대응할 수 있습니다.

기본값으로는 **공개 무료 Lavalink 노드**를 사용하도록 설정되어 있습니다 (`index.js` 상단의 `LAVALINK_NODES`). 이런 공개 노드는 개인이 무료로 운영하는 경우가 많아서 **언제든 갑자기 다운되거나 사라질 수 있습니다.**

`/재생`이 계속 안 되면:
1. Render 로그에서 `Lavalink 노드 연결 오류`가 뜨는지 확인하세요.
2. https://github.com/topics/free-lavalink 같은 곳에서 최신 공개 노드를 찾아보세요.
3. 찾은 노드 정보를 아래처럼 환경변수로 등록하면 코드 수정 없이 바로 교체됩니다 (Render Environment 탭에서 추가):
   - `LAVALINK_HOST`
   - `LAVALINK_PORT`
   - `LAVALINK_PASSWORD`
   - `LAVALINK_SECURE` (`true` 또는 `false`)

더 안정적으로 쓰고 싶다면, 직접 자신만의 Lavalink 서버를 무료 클라우드(Oracle Cloud 등)에 올려서 쓰는 방법도 있습니다 (별도 설정이 필요합니다).

## 참고 사항

- TTS는 마이크로소프트 엣지의 무료 음성 엔진(`msedge-tts` 패키지)을 사용하며 인터넷 연결이 필요합니다.
- 오디오 인코딩은 `opusscript`(순수 JS)를 사용해서 별도 컴파일 도구 없이 `npm install`만으로 어떤 환경에서도 설치가 잘 됩니다.
- 노래가 재생 중일 때는 입퇴장 안내가 음성 연결 충돌을 피하기 위해 건너뛰어집니다 (텍스트로도 안내되지 않고 조용히 스킵됩니다).
- 안내가 다 끝나면 3초 후 봇이 자동으로 채널을 나갑니다 (`LEAVE_DELAY_MS` 값으로 조절 가능).
- 안내 문구를 바꾸고 싶으면 `index.js`의 `speak(...)` 호출 부분 문자열만 수정하면 됩니다.

## 문제 해결

- **소리가 안 나요 (입퇴장 안내)**: 봇에게 `Speak` 권한이 있는지, 채널에 인원 제한이 걸려있지 않은지 확인하세요.
- **연결 오류(음성 채널 연결 실패)**: `libsodium-wrappers` 설치가 잘 됐는지 확인하세요.
- **`/재생`이 안 돼요**: 위 "노래 재생 구조" 항목을 참고해서 Lavalink 노드 상태를 확인하세요.
- **슬래시 명령어가 안 떠요**: 봇을 `applications.commands` 스코프로 다시 초대했는지, 디스코드 앱을 완전히 껐다 켰는지 확인하세요.
