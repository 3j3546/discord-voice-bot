# 디스코드 음성채널 입퇴장 알림 + 이미지 생성 봇

음성채널에 누군가 들어오거나 나가면 음성(TTS)으로 안내하고, `/이미지` 명령어로 AI 이미지도 생성하는 봇입니다.

## 1. 디스코드 봇 생성하기

1. https://discord.com/developers/applications 접속 후 로그인
2. "New Application" 클릭 → 이름 입력
3. 왼쪽 메뉴에서 **Bot** 클릭 → "Add Bot"
4. **TOKEN** 항목에서 "Reset Token" → 토큰 복사 (외부에 절대 노출 금지)
5. 왼쪽 메뉴 **OAuth2 → URL Generator**
   - SCOPES: `bot`, `applications.commands` (슬래시 명령어 사용에 필수)
   - BOT PERMISSIONS: `View Channels`, `Connect`, `Speak`
6. 생성된 URL로 접속해서 봇을 원하는 서버에 초대

## 2. 로컬 환경 설정

Node.js 18 이상이 필요합니다.

```bash
npm install
cp .env.example .env
```

`.env` 파일을 열어 `DISCORD_TOKEN`에 토큰을 붙여넣으세요.

## 3. 실행

```bash
npm start
```

콘솔에 `✅ 로그인 완료`가 뜨면 정상 작동 중입니다.

## 입퇴장 알림

- 누군가 음성채널에 들어오거나 나가거나 이동하면 음성(TTS)으로 안내하고, **그 음성채널의 채팅창(음성채널 안의 텍스트 채팅)에도 글자로 남깁니다** (🟢 입장 / 🔴 퇴장 / 🔀 이동)
- `/설정` → `1` — 글자 알림을 올릴 텍스트 채널을 지정합니다 (서버 관리 권한 필요). 지정하면 어느 음성채널 이야기인지 `— 🔊 채널이름`이 같이 붙습니다
- `/설정` → `1` → `해제` — 지정을 해제하고 다시 각 음성채널 채팅에 올립니다. `/설정확인`에서 현재 지정 상태를 볼 수 있습니다
- 알림 채널·목소리·속도 설정은 DB(아래 "DB 설정")를 연결하면 봇이 재시작돼도 유지됩니다. DB가 없으면 메모리에만 저장돼서 재시작 시 초기화됩니다
- 글자 알림을 남기려면 봇에게 그 음성채널의 **메시지 보내기** 권한이 있어야 합니다 (없으면 글자만 건너뛰고 음성 안내는 그대로 동작)

## 슬래시 명령어

**설정 (서버 관리 권한 필요)**
- `/목소리 설정:남자` 또는 `설정:여자` — 안내 음성 목소리 변경
- `/속도 퍼센트:25` — 말하기 속도 변경 (-50~100)
- `/설정확인` — 현재 설정 확인

> 주의: DB(아래 "DB 설정")를 연결하지 않으면 설정이 메모리에만 저장되어 봇이 재시작될 때 기본값(남자, +25%)으로 초기화됩니다.

**TTS (누구나 사용 가능, 음성 채널에 들어가 있어야 함)**
- `/tts 내용:박박` — 입력한 내용을 봇이 지금 들어가 있는 음성 채널에서 읖어줍니다 (글자 수 제한 없음, 디스코드 명령어 입력창 한계인 최대 6000자까지 가능)
- `/tts 내용:박박 목소리:여자` — 그 한 번만 다른 목소리로 말하게 할 수 있습니다 (서버 기본 목소리는 그대로 유지됨)
- 목소리를 안 고르면 `/목소리`로 설정해둔 서버 기본 목소리로 말합니다

**이미지 생성 (누구나 사용 가능)**
- `/이미지 프롬프트:설명` — AI로 이미지를 생성합니다 (Pollinations.ai, API 키 불필요)
  - 한국어로 입력하면 자동으로 영어로 번역해서 생성합니다 (DeepL 번역 API 사용)
  - 익명 사용은 15초에 한 번으로 제한되어 있습니다

**투표 (누구나 사용 가능)**
- `/투표 질문:저녁 뭐먹지 항목1:피자 항목2:치킨 항목3:족발` — 최대 5개 항목까지 가능, 숫자 이모지로 반응(투표)하는 방식
- `/투표종료` — 그 채널의 가장 최근 투표를 마감하고 득표수 결과를 보여줍니다

**룰렛 (누구나 사용 가능)**
- `/룰렛 항목:피자,치킨,족발,탕수육` — 쉼표로 구분한 항목(2~10개) 중 하나를 룰렛이 돌아가는 GIF 애니메이션으로 무작위로 뽑아줍니다
- 외부 API 없이 봇이 직접 돌림판 이미지를 그려서 애니메이션으로 만듭니다 (API 키 불필요)
- 생성에 몇 초 정도 걸립니다 (디스코드에 "생각 중..."으로 표시되다가 완성되면 GIF가 뜹니다)

**끝말잇기 (누구나 사용 가능)**
- `/끝말잇기시작` — 이 채널에서 끝말잇기 시작 (봇은 심판만 함, 실제로는 채팅하는 사람들끼리 진행)
- 그 다음부터는 그냥 채팅으로 단어를 입력하면 됩니다 (두 글자 이상, 한글만). 규칙에 맞으면 ✅, 틀리면 ❌ 반응과 함께 이유를 알려줍니다
- 두음법칙(예: '~력' 다음 '역'으로 시작 가능)도 어느 정도 지원합니다
- **국립국어원 표준국어대사전 API**(`KOREAN_DICT_API_KEY` 환경변수)로 실제 사전에 있는 단어인지 검증하고, **한방단어**(다음 사람이 이을 수 없는 단어, 예: 이리듐)를 자동으로 판별합니다
  - 한방단어는 첫 단어로는 낼 수 없습니다
  - 게임 중 한방단어를 내면 즉시 그 사람이 승리, 직전에 단어를 낸 사람이 패배로 게임이 끝납니다
  - API 키를 등록하지 않으면 사전/한방단어 검증 없이 형식(글자 수, 한글 여부, 중복)만 검사합니다
- `/끝말잇기종료` — 진행 중인 끝말잇기를 종료하고, 마지막 단어를 낸 사람 승리 / 그 전 사람 패배로 표시합니다

**가위바위보 (최대 2명)**
- `/가위바위보` — 버튼(가위/바위/보)이 뜹니다. 서로 다른 두 사람이 각자 버튼을 누르면 자동으로 승패를 판정합니다
- 비기면 자동으로 다음 판이 시작됩니다

**날씨 (누구나 사용 가능)**
- `/날씨 지역:청주시` — 구/동 단위로 나눠서 묻지 않고, 해당 지역의 오늘 날씨를 한 번에 종합해서 알려줍니다 (현재 기온, 체감온도, 최고/최저 기온, 습도)
- API 키 불필요 (wttr.in 사용)

**번역 (누구나 사용 가능)**
- `/번역 텍스트:안녕하세요 언어:영어` — DeepL 번역 API로 번역합니다
- 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어, 베트남어 지원
- **`DEEPL_API_KEY` 환경변수가 필요합니다** (deepl.com에서 무료 가입, 신용카드 불필요, 한 달에 500,000자까지 무료)
  1. https://www.deepl.com/ko/pro-api 접속 → "무료로 시작하기"로 가입 (신용카드 필요 없음)
  2. 가입 후 계정 → API 키 메뉴에서 발급된 키 확인 (끝에 `:fx`가 붙어있으면 무료 키가 맞습니다)
  3. Render 환경변수에 `DEEPL_API_KEY`로 등록
- 환경변수를 등록하지 않으면 `/번역`과 `/이미지`의 한국어 자동 번역이 작동하지 않습니다 (오류 메시지가 뜹니다)

**점수판 (KBO 야구, 누구나 사용 가능)**
- `/점수판 구단:두산 베어스` — 오늘 그 구단의 KBO 경기 점수를 보여줍니다
- 공식 무료 API가 없어서 비공식 경로로 데이터를 가져옵니다 — 언제든 갑자기 안 될 수 있습니다 (그럴 땐 알려주시면 고쳐드릴게요)

**운세 (누구나 사용 가능)**
- `/운세 월:9 일:25` — 입력한 생일을 기준으로 별자리를 계산해서 오늘의 운세를 보여줍니다
- API Ninjas의 Horoscope API(영어)로 가져온 뒤 DeepL로 한국어 번역해서 보여줍니다
- **`APININJAS_API_KEY` 환경변수가 필요합니다** (api-ninjas.com에서 무료 가입, 신용카드 불필요)
  1. https://api-ninjas.com/ 접속 → 회원가입 (신용카드 필요 없음)
  2. 로그인 후 대시보드에서 API 키 확인
  3. Render 환경변수에 `APININJAS_API_KEY`로 등록
- `DEEPL_API_KEY`도 함께 필요합니다 (번역에 사용, 위 "번역" 항목 참고)

**명언 (누구나 사용 가능)**
- `/명언` — 오늘의 명언(한국어)을 하나 보여줍니다
- **국립국어원/별도 API 키 불필요** (korean-advice-open-api, 무료·무가입)

**삼행시 (누구나 사용 가능)**
- `/삼행시 제시어:디스코드` — 한글 2~5글자 제시어로 AI가 N행시를 지어줍니다 (3글자면 삼행시, 5글자면 오행시)
- 무료 텍스트 AI(Pollinations, API 키 불필요)를 쓰며, 각 줄이 제시어 글자로 시작하지 않으면 자동으로 한 번 더 시도합니다
- 무료 서버라 가끔 실패할 수 있어요 (그럴 땐 잠시 후 다시 시도)

## 베라31 (베스킨라빈스31)

- `/베라31` — 시작한 사람과 **참가** 버튼을 누른 1명, 총 2명이 해요. 순서는 무작위로 정해요.
- 차례가 오면 버튼으로 숫자를 1~3개 골라요. 처음엔 `1`, `1~2`, `1~3`, 다음엔 이어서 `4`, `4~5`, `4~6`처럼 나와요.
- 번갈아 하다가 **31을 말하는 사람이 져요.** 아무도 안 누르면 모집은 2분, 진행 중에는 3분 뒤 끝나요.

## 방송 시작 알림 (치지직 · SOOP · 유튜브, DB 필요)

등록한 방송 채널이 켜지면 서버 채널이나 DM으로 알려줘요. API 키는 필요 없어요.

- `/방송알림추가 플랫폼:치지직 주소:https://chzzk.naver.com/채널ID` — 서버 채널로 받기 (서버 관리 권한 필요, `채널`·`역할` 멘션 선택 가능)
- 알림 글자 중 **지금 바로 보러 가기**를 누르면 방송으로 가요. `역할`에 `@everyone`을 고르면 실제 @everyone 멘션으로 나가요(봇에 "@everyone 멘션" 권한 필요).
- `/방송알림추가 ... 보낼곳:내 DM` — 내 DM으로 받기 (누구나, 한 사람당 5개)
- `/방송알림목록` / `/방송알림삭제 번호:abc12`
- 주소는 URL, 치지직 32자리 ID, SOOP 아이디, 유튜브 `@핸들` 또는 `UC...` 채널 ID 모두 돼요.
- DB(`streams`)에는 구독 정보만 저장하고, 알림을 보낸 기록·방송 상태는 저장하지 않아요. 확인(2분마다)할 때는 DB를 쓰지 않아서 Upstash 사용량이 거의 늘지 않아요.
- 봇이 꺼져 있던 동안 시작한 방송은 알리지 못하고, 봇이 켜졌을 때 이미 방송 중이던 건 알림 없이 기억만 해요.
- 한도: 서버당 채널 알림 10개, 봇 전체 60개 채널(유튜브는 15개).

## 날씨 그림

`/날씨` 결과에 날씨에 맞는 그림이 같이 나와요 (맑음·구름많음·흐림·비·소나기·눈·눈비·천둥·안개). 저녁 7시~아침 6시(한국 시간)에는 밤 그림으로 나와요. 코드로 직접 그린 그림이라 인터넷에서 사진을 가져오지 않아요. 그림을 못 만들면 글만 나와요.

## 채널 추천 (유튜브 · SOOP)

- `/채널추천 플랫폼:유튜브` / `/채널추천 플랫폼:SOOP(숲)` — 지금 방송 중인 인기 채널 8개를 보여줘요. `검색어`(예: 로블록스)를 넣으면 그 주제로 좁혀요.
- DB를 쓰지 않고 5분 동안 결과를 기억해요. 성인(19세)·비밀번호·구독자 전용 방송은 빼요.

## 로블록스 조회 (`/로블록스`)

- `/로블록스 유저 이름:아이디` — 프로필 사진, 가입일, 친구·팔로워·팔로잉 수
- `/로블록스 게임 이름:게임이름(또는 게임 주소)` — 지금 접속자, 총 방문, 즐겨찾기, 좋아요 비율, 제작자
- 로블록스 공개 API를 써서 키나 로그인이 필요 없어요.

## 추첨 (`/추첨`, 서버 관리 권한 필요)

- `/추첨 상품:치킨 당첨인원:2 시간:30분` → 🎉 참가 버튼이 달린 글이 올라가요. (시간은 1분 ~ 7일)
- 버튼을 누르면 참가, 다시 누르면 취소예요. 마감되면 봇이 알아서 뽑아서 알려줘요.
- DB가 있으면 봇이 재시작돼도 이어져요. 끝나면 DB 기록은 바로 지워요.
- 중간에 끝내거나 취소하려면 `/설정` → `10`.

## 문의 티켓 (`/설정` → `11`)

- 담당자 역할, (선택) 카테고리, 패널 채널을 정하면 "📩 문의하기" 버튼 패널이 올라가요.
- 누르면 그 사람과 담당자만 볼 수 있는 비공개 채널이 생기고, 🔒 닫기 버튼으로 지워요. 한 사람당 1개만 열 수 있어요.
- 봇 역할에 **채널 관리** 권한이 필요해요.

## 아침 브리핑 (`/설정` → `12`)

- 켜두면 매일 정한 시각(한국 시간, 기본 08:00)에 날씨(+날씨 그림), 오늘 날짜, 오늘 생일인 사람을 보내줘요.
- 채널을 안 정하면 알림 채널로 가요. 봇이 늦게 깨어나도 3시간 안에는 보내요.
- DB가 없으면 봇이 재시작될 때 설정이 사라져요. (생일 표시는 DB가 있어야 해요.)

## 서버 설정 도우미 (`/설정`, 서버 관리 권한 필요)

관리자 설정은 전부 `/설정` 하나로 해요. `/설정`을 치면 번호 목록이 나오고, **채팅창에 번호를 보내서** 고르면 돼요. (종료는 `0`, 90초 동안 답이 없으면 자동으로 닫혀요. 설정하는 동안 그 사람의 메시지는 챗봇·보안 검사가 건드리지 않아요.)

### 보안 기능 설명
처음에는 전부 꺼져 있어요. 관리자(Administrator) 권한이 있는 사람, 서버 주인, 신뢰 유저는 검열에서 빠져요.

- **타 서버 초대링크 검열**: 다른 서버의 초대링크를 보내면 메시지를 지우고 타임아웃해요. (이 서버 초대링크는 괜찮아요)
- **도배·단타 검열**: 짧은 시간에 여러 개(7초에 6개), 같은 내용 4번 이상, 무의미하게 긴 글을 보내면 지우고 타임아웃해요.
- **서버테러 방어**: 10초 안에 채널·역할 삭제나 추방·차단을 3번 이상 하면 그 사람의 위험 권한 역할을 회수하고(봇이면 추방) 1시간 타임아웃해요. 감사 로그를 읽어서 동작해요.
- **메시지 명령**: `입퇴장아 @유저 1시간 타임아웃해줘` (타임아웃·경고·추방·차단). 시간은 `30초`·`3분`·`1시간 30분`·`2일`처럼 쓰고, `해제`를 붙이면 풀어요(`@유저 타임아웃 해제`, `차단 해제`, `경고 해제`). 명령한 사람에게 해당 권한이 있어야 하고, 자기보다 높은 역할에는 못 써요.
- **블랙리스트**: 이 서버에서 관리하는 목록이고, 블랙리스트 유저가 말하면 알림 채널에 알려줘요.
- **봇 권한**: 메시지 관리, 멤버 타임아웃, 감사 로그 보기, 역할 관리, 멤버 추방/차단. 그리고 서버 설정에서 **봇 역할을 처벌할 유저들의 역할보다 위로** 올려야 해요.
- 설정은 DB에 서버당 한 키(`security:서버ID`)로 저장돼요. 메시지 검사는 전부 메모리에서 해서 DB 사용량이 거의 늘지 않아요(경고 횟수만 `warns:서버ID`에 저장).

## 정기 배송 알림 (`/정기배송알림`, 알림은 DM으로만)

- `/정기배송알림 등록 택배사 운송장번호 시간` — 예: 시간에 `9, 13, 18`이면 매일 9시·13시·18시(한국 시간)에 DM으로 배송 상태가 와요. (하루 최대 4번, 한 사람당 3개까지)
- 등록할 때 실제로 조회해서 **택배사나 운송장번호가 안 맞으면 등록이 안 돼요.** 이미 배송 완료된 택배, DM을 막아둔 경우도 등록이 안 돼요.
- 배송이 완료되면 마지막 알림 후 자동으로 끝나고, 30일이 지나도 끝나요. 조회가 5번 연속 실패해도 끝나요.
- `/정기배송알림 목록`, `/정기배송알림 삭제 번호`
- DB가 있으면 봇이 재시작돼도 이어져요. (끝난 알림은 DB에서 지워요.)

## DB 설정 (Upstash Redis, 무료·카드 불필요)

서버 설정 저장, 생일, 리마인더에 쓰입니다. **없어도 봇의 나머지 기능은 전부 동작**하고, 생일/리마인더 명령어만 "DB 설정이 필요해요"라고 안내합니다.

1. https://upstash.com 접속 → Google/GitHub로 로그인 (신용카드 필요 없음)
2. **Create Database** → 이름 아무거나, Type은 **Regional**, Region은 **Asia Pacific (Tokyo)** 선택 → Free 플랜으로 생성
3. 만들어진 DB 화면의 **REST API** 섹션(또는 `.env` 탭)에서 두 값을 복사
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
4. Render → 서비스 → Environment에 위 두 개를 그대로 추가 → 저장하면 자동 재배포됩니다
5. 로그에 `🗄️ DB(Upstash Redis) 연결됨`이 뜨면 성공입니다

**생일 (누구나 사용 가능, DB 필요)**
- `/생일등록 월:9 일:25` — 내 생일 등록. 그날 한국 시간 오전 9시 이후 알림 채널(`/설정` → 1번으로 지정, 없으면 서버 기본 채널)에서 축하해줍니다
- `/생일삭제` — 내 생일 삭제 / `/생일목록` — 이 서버 등록 목록 (2/29생은 평년엔 2/28에 축하)

**리마인더 (누구나 사용 가능, DB 필요)**
- `/리마인더 언제:2시간 30분 내용:빨래 널기` — 정해진 시간 뒤 같은 채널에서 나를 멘션해서 알려줍니다 (1분~30일, `10분` / `2시간` / `1일 3시간 30분` 형식, 한 사람당 최대 10개)
- `/리마인더목록` — 내 리마인더 번호 확인 / `/리마인더삭제 번호:abc123` — 취소
- 확인 주기는 1분이라 알림이 최대 1분쯤 늦을 수 있고, 봇이 쉬고 있던 사이 시각이 지났으면 켜진 직후 늦게라도 전달됩니다

## 참고 사항

- TTS는 마이크로소프트 엣지의 무료 음성 엔진(`msedge-tts` 패키지)을 사용하며 인터넷 연결이 필요합니다.
- 오디오 인코딩은 `opusscript`(순수 JS)를 사용해서 별도 컴파일 도구 없이 `npm install`만으로 어떤 환경에서도 설치가 잘 됩니다.
- 아무것도 재생할 게 없으면 3초 후 봇이 자동으로 채널을 나갑니다 (`LEAVE_DELAY_MS` 값으로 조절 가능).
- 안내 문구를 바꾸고 싶으면 `index.js`의 `speak(...)` 호출 부분 문자열만 수정하면 됩니다.

## 문제 해결

- **소리가 안 나요**: 봇에게 `Speak` 권한이 있는지, 채널에 인원 제한이 걸려있지 않은지 확인하세요.
- **연결 오류(음성 채널 연결 실패)**: `libsodium-wrappers` 설치가 잘 됐는지 확인하세요.
- **`/이미지`가 안 돼요**: 15초 안에 너무 여러 번 요청했을 수 있습니다. 잠시 후 다시 시도하세요.
- **슬래시 명령어가 안 떠요**: 봇을 `applications.commands` 스코프로 다시 초대했는지, 디스코드 앱을 완전히 껐다 켰는지 확인하세요.
- **모든 슬래시 명령어가 "애플리케이션이 작동하지 않아요" / `Unknown interaction`으로 실패해요 (입퇴장 안내는 정상 작동)**:
  거의 대부분 Render 무료 플랜의 **콜드 스타트(sleep)** 때문입니다. 무료 웹 서비스는 일정 시간 요청이 없으면
  서버가 잠들고, 다음 요청이 왔을 때 다시 깨어나는 데 몇 초~50초 이상 걸릴 수 있습니다. 디스코드는 슬래시
  명령어에 **3초 안에** 응답하지 않으면 그 요청 자체를 무효화시키는데, 봇이 잠들어 있다가 늦게 깨어나면
  코드가 실행되기도 전에 이미 요청이 무효화되어서 `Unknown interaction` 오류가 납니다. 입퇴장 안내는 이
  3초 제한이 없는 이벤트라서, 서버가 느리게 깨어나도 그냥 몇 초 늦게 동작할 뿐 실패로 보이지 않습니다.
  - 최신 버전의 `index.js`는 이 경우를 자동으로 로그에 남깁니다. Render 로그에서
    `⚠️ 인터랙션(...) 처리 시작이 ___ms 지연됐어요` 라는 줄이 보이면 바로 이 문제입니다.
  - **확인 방법**: UptimeRobot 등에서 **이 봇 서비스(`discord-voice-bot-ggu3.onrender.com` 같은 주소)** 를
    5분 이내 간격으로 핑을 보내고 있는지, 그리고 그 모니터가 실제로 계속 성공(Up)하고 있는지 확인하세요.
    (다른 서비스, 특히 이제 쓰지 않는 Lavalink 모니터를 착각해서 보고 있지 않은지도 확인하세요.)
  - **근본적인 해결**: Render 무료 플랜 자체가 언제든 다시 잠들 수 있는 구조라서, 핑만으로는 100% 막기 어려울
    때가 있습니다. 확실히 해결하려면 Render의 유료 플랜(Starter, 월 7달러 정도)으로 올리거나, 잠들지 않는
    다른 호스팅으로 옮기는 게 가장 확실합니다.
