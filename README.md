디스코드 음성채널 입퇴장 알림 봇
음성채널에 누군가 들어오거나 나가면, 봇이 그 채널에 들어가서 "OO님이 입장했습니다" / "OO님이 퇴장했습니다" 라고 음성(TTS)으로 알려주는 봇입니다.
1. 디스코드 봇 생성하기
https://discord.com/developers/applications 접속 후 로그인
"New Application" 클릭 → 이름 입력 (예: 입퇴장 알리미)
왼쪽 메뉴에서 Bot 클릭 → "Add Bot"
TOKEN 항목에서 "Reset Token" → 토큰 복사 (외부에 절대 노출 금지)
왼쪽 메뉴 OAuth2 → URL Generator
SCOPES: `bot`
BOT PERMISSIONS: `View Channels`, `Connect`, `Speak`
생성된 URL로 접속해서 봇을 원하는 서버에 초대
> 참고: 이 봇은 음성상태(입장/퇴장)만 감지하므로 별도의 Privileged Intent(메시지 콘텐츠 등)를 켤 필요가 없습니다.
2. 로컬 환경 설정
Node.js 18 이상이 필요합니다.
```bash
npm install
cp .env.example .env
```
`.env` 파일을 열어 `DISCORD_TOKEN`에 아까 복사한 토큰을 붙여넣으세요.
3. 실행
```bash
npm start
```
콘솔에 `✅ 로그인 완료`가 뜨면 정상 작동 중입니다. 이제 음성채널에 입장/퇴장하면 봇이 자동으로 따라 들어와서 안내 음성을 재생합니다.
참고 사항
TTS는 마이크로소프트 엣지의 무료 음성 엔진(`msedge-tts` 패키지)을 사용하며 인터넷 연결이 필요합니다.
노래 재생은 `play-dl` 패키지로 유튜브에서 검색/스트리밍합니다. 유튜브 정책 변화로 가끔 갑자기 안 될 수 있습니다 (그럴 땐 `npm update play-dl`로 업데이트해보세요).
오디오 인코딩은 `opusscript`(순수 JS)를 사용해서 별도 컴파일 도구 없이 `npm install`만으로 어떤 환경에서도 설치가 잘 됩니다.
여러 명이 동시에 들어오고 나가도 순서대로 큐에 쌓여서 재생되므로 음성이 겹치지 않습니다.
아무것도 재생할 게 없으면 3초 후 봇이 자동으로 채널을 나갑니다 (`LEAVE_DELAY_MS` 값으로 조절 가능).
안내 문구를 바꾸고 싶으면 `index.js`의 `speak(...)` 호출 부분 문자열만 수정하면 됩니다.
슬래시 명령어
설정 (서버 관리 권한 필요)
`/목소리 설정:남자` 또는 `설정:여자` — 안내 음성 목소리 변경
`/속도 퍼센트:25` — 말하기 속도 변경 (-50~100)
`/설정확인` — 현재 설정 확인
> 주의: 설정은 메모리에만 저장되어 봇이 재시작되면 기본값(남자, +25%)으로 초기화됩니다.
음악 (누구나 사용 가능)
`/재생 검색어:노래 제목 또는 유튜브 링크`
`/스킵`, `/정지`, `/일시정지`, `/재개`, `/대기열`
> 슬래시 명령어를 쓰려면 봇 초대 시 `applications.commands` 스코프가 필요합니다. 개발자 포털 OAuth2 URL Generator에서 `bot`과 함께 체크해서 다시 초대하세요.
문제 해결
소리가 안 나요: 봇에게 `Speak` 권한이 있는지, 채널에 인원 제한이 걸려있지 않은지 확인하세요.
연결 오류(음성 채널 연결 실패): `libsodium-wrappers` 설치가 잘 됐는지 확인하세요 (`npm install`이 정상 종료됐는지).
`/재생`이 안 돼요: 유튜브 쪽 변경으로 `play-dl`이 일시적으로 막힐 수 있습니다. Render 콘솔에서 재배포하거나 `npm update play-dl` 후 다시 배포해보세요.
슬래시 명령어가 안 떠요: 봇을 `applications.commands` 스코프로 다시 초대했는지, 디스코드 앱을 완전히 껐다 켰는지 확인하세요.
