# 디스코드 음성채널 입퇴장 알림 + 이미지 생성 봇

음성채널에 누군가 들어오거나 나가면 음성(TTS)으로 안내하고, `/이미지` 명령어로 AI 이미지도 생성하는 봇입니다.

## 1. 디스코드 봇 생성하기

1. https://discord.com/developers/applications 접속 후 로그인
2. "New Application" 클릭 → 이름 입력
3. 왼쪽 메뉴에서 **Bot** 클릭 → "Add Bot"
4. **TOKEN** 항목에서 "Reset Token" → 토큰 복사 (외부에 절대 노출 금지)
5. 왼쪽 메뉴 **OAuth2 → URL Generator**
   - SCOPES: `bot`, `applications.commands` (슬래시 명령어 사용에 필수)
   - BOT PERMISSIONS: `View Channels`, `Connect`, `Speak`
6. 생성된 URL로 접속해서 봇을 원하는 서버에 초대

## 2. 로컬 환경 설정

Node.js 18 이상이 필요합니다.

```bash
npm install
cp .env.example .env
```

`.env` 파일을 열어 `DISCORD_TOKEN`에 토큰을 붙여넣으세요.

## 3. 실행

```bash
npm start
```

콘솔에 `✅ 로그인 완료`가 뜨면 정상 작동 중입니다.

## 슬래시 명령어

**설정 (서버 관리 권한 필요)**
- `/목소리 설정:남자` 또는 `설정:여자` — 안내 음성 목소리 변경
- `/속도 퍼센트:25` — 말하기 속도 변경 (-50~100)
- `/설정확인` — 현재 설정 확인

> 주의: 설정은 메모리에만 저장되어 봇이 재시작되면 기본값(남자, +25%)으로 초기화됩니다.

**이미지 생성 (누구나 사용 가능)**
- `/이미지 프롬프트:설명` — AI로 이미지를 생성합니다 (Pollinations.ai, API 키 불필요)
  - 한국어로 입력하면 자동으로 영어로 번역해서 생성합니다 (DeepL 번역 API 사용)
  - 익명 사용은 15초에 한 번으로 제한되어 있습니다

**투표 (누구나 사용 가능)**
- `/투표 질문:저녁 뭐먹지 항목1:피자 항목2:치킨 항목3:족발` — 최대 5개 항목까지 가능, 숫자 이모지로 반응(투표)하는 방식
- `/투표종료` — 그 채널의 가장 최근 투표를 마감하고 득표수 결과를 보여줍니다

**끝말잇기 (누구나 사용 가능)**
- `/끝말잇기시작` — 이 채널에서 끝말잇기 시작 (봇은 심판만 함, 실제로는 채팅하는 사람들끼리 진행)
- 그 다음부터는 그냥 채팅으로 단어를 입력하면 됩니다 (두 글자 이상, 한글만). 규칙에 맞으면 ✅, 틀리면 ❌ 반응과 함께 이유를 알려줍니다
- 두음법칙(예: '~력' 다음 '역'으로 시작 가능)도 어느 정도 지원합니다
- **국립국어원 표준국어대사전 API**(`KOREAN_DICT_API_KEY` 환경변수)로 실제 사전에 있는 단어인지 검증하고, **한방단어**(다음 사람이 이을 수 없는 단어, 예: 이리듐)를 자동으로 판별합니다
  - 한방단어는 첫 단어로는 낼 수 없습니다
  - 게임 중 한방단어를 내면 즉시 그 사람이 승리, 직전에 단어를 낸 사람이 패배로 게임이 끝납니다
  - API 키를 등록하지 않으면 사전/한방단어 검증 없이 형식(글자 수, 한글 여부, 중복)만 검사합니다
- `/끝말잇기종료` — 진행 중인 끝말잇기를 종료하고, 마지막 단어를 낸 사람 승리 / 그 전 사람 패배로 표시합니다

**가위바위보 (최대 2명)**
- `/가위바위보` — 버튼(가위/바위/보)이 뜹니다. 서로 다른 두 사람이 각자 버튼을 누르면 자동으로 승패를 판정합니다
- 비기면 자동으로 다음 판이 시작됩니다

**날씨 (누구나 사용 가능)**
- `/날씨 지역:청주시` — 구/동 단위로 나눠서 묻지 않고, 해당 지역의 오늘 날씨를 한 번에 종합해서 알려줍니다 (현재 기온, 체감온도, 최고/최저 기온, 습도)
- API 키 불필요 (wttr.in 사용)

**번역 (누구나 사용 가능)**
- `/번역 텍스트:안녕하세요 언어:영어` — DeepL 번역 API로 번역합니다
- 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어, 베트남어 지원
- **`DEEPL_API_KEY` 환경변수가 필요합니다** (deepl.com에서 무료 가입, 신용카드 불필요, 한 달에 500,000자까지 무료)
  1. https://www.deepl.com/ko/pro-api 접속 → "무료로 시작하기"로 가입 (신용카드 필요 없음)
  2. 가입 후 계정 → API 키 메뉴에서 발급된 키 확인 (끝에 `:fx`가 붙어있으면 무료 키가 맞습니다)
  3. Render 환경변수에 `DEEPL_API_KEY`로 등록
- 환경변수를 등록하지 않으면 `/번역`과 `/이미지`의 한국어 자동 번역이 작동하지 않습니다 (오류 메시지가 뜹니다)

**점수판 (KBO 야구, 누구나 사용 가능)**
- `/점수판 구단:두산 베어스` — 오늘 그 구단의 KBO 경기 점수를 보여줍니다
- 공식 무료 API가 없어서 비공식 경로로 데이터를 가져옵니다 — 언제든 갑자기 안 될 수 있습니다 (그럴 땐 알려주시면 고쳐드릴게요)

## 참고 사항

- TTS는 마이크로소프트 엣지의 무료 음성 엔진(`msedge-tts` 패키지)을 사용하며 인터넷 연결이 필요합니다.
- 오디오 인코딩은 `opusscript`(순수 JS)를 사용해서 별도 컴파일 도구 없이 `npm install`만으로 어떤 환경에서도 설치가 잘 됩니다.
- 아무것도 재생할 게 없으면 3초 후 봇이 자동으로 채널을 나갑니다 (`LEAVE_DELAY_MS` 값으로 조절 가능).
- 안내 문구를 바꾸고 싶으면 `index.js`의 `speak(...)` 호출 부분 문자열만 수정하면 됩니다.

## 문제 해결

- **소리가 안 나요**: 봇에게 `Speak` 권한이 있는지, 채널에 인원 제한이 걸려있지 않은지 확인하세요.
- **연결 오류(음성 채널 연결 실패)**: `libsodium-wrappers` 설치가 잘 됐는지 확인하세요.
- **`/이미지`가 안 돼요**: 15초 안에 너무 여러 번 요청했을 수 있습니다. 잠시 후 다시 시도하세요.
- **슬래시 명령어가 안 떠요**: 봇을 `applications.commands` 스코프로 다시 초대했는지, 디스코드 앱을 완전히 껐다 켰는지 확인하세요.
- **모든 슬래시 명령어가 "애플리케이션이 작동하지 않아요" / `Unknown interaction`으로 실패해요 (입퇴장 안내는 정상 작동)**:
  거의 대부분 Render 무료 플랜의 **콜드 스타트(sleep)** 때문입니다. 무료 웹 서비스는 일정 시간 요청이 없으면
  서버가 잠들고, 다음 요청이 왔을 때 다시 깨어나는 데 몇 초~50초 이상 걸릴 수 있습니다. 디스코드는 슬래시
  명령어에 **3초 안에** 응답하지 않으면 그 요청 자체를 무효화시키는데, 봇이 잠들어 있다가 늦게 깨어나면
  코드가 실행되기도 전에 이미 요청이 무효화되어서 `Unknown interaction` 오류가 납니다. 입퇴장 안내는 이
  3초 제한이 없는 이벤트라서, 서버가 느리게 깨어나도 그냥 몇 초 늦게 동작할 뿐 실패로 보이지 않습니다.
  - 최신 버전의 `index.js`는 이 경우를 자동으로 로그에 남깁니다. Render 로그에서
    `⚠️ 인터랙션(...) 처리 시작이 ___ms 지연됐어요` 라는 줄이 보이면 바로 이 문제입니다.
  - **확인 방법**: UptimeRobot 등에서 **이 봇 서비스(`discord-voice-bot-ggu3.onrender.com` 같은 주소)** 를
    5분 이내 간격으로 핑을 보내고 있는지, 그리고 그 모니터가 실제로 계속 성공(Up)하고 있는지 확인하세요.
    (다른 서비스, 특히 이제 쓰지 않는 Lavalink 모니터를 착각해서 보고 있지 않은지도 확인하세요.)
  - **근본적인 해결**: Render 무료 플랜 자체가 언제든 다시 잠들 수 있는 구조라서, 핑만으로는 100% 막기 어려울
    때가 있습니다. 확실히 해결하려면 Render의 유료 플랜(Starter, 월 7달러 정도)으로 올리거나, 잠들지 않는
    다른 호스팅으로 옮기는 게 가장 확실합니다.
