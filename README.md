# 디스코드 음성채널 입퇴장 알림 봇

음성채널에 누군가 들어오거나 나가면, 봇이 그 채널에 들어가서 "OO님이 입장했습니다" / "OO님이 퇴장했습니다" 라고 음성(TTS)으로 알려주는 봇입니다.

## 1. 디스코드 봇 생성하기

1. https://discord.com/developers/applications 접속 후 로그인
2. "New Application" 클릭 → 이름 입력 (예: 입퇴장 알리미)
3. 왼쪽 메뉴에서 **Bot** 클릭 → "Add Bot"
4. **TOKEN** 항목에서 "Reset Token" → 토큰 복사 (외부에 절대 노출 금지)
5. 왼쪽 메뉴 **OAuth2 → URL Generator**
   - SCOPES: `bot`
   - BOT PERMISSIONS: `View Channels`, `Connect`, `Speak`
6. 생성된 URL로 접속해서 봇을 원하는 서버에 초대

> 참고: 이 봇은 음성상태(입장/퇴장)만 감지하므로 별도의 Privileged Intent(메시지 콘텐츠 등)를 켤 필요가 없습니다.

## 2. 로컬 환경 설정

Node.js 18 이상이 필요합니다.

```bash
npm install
cp .env.example .env
```

`.env` 파일을 열어 `DISCORD_TOKEN`에 아까 복사한 토큰을 붙여넣으세요.

## 3. 실행

```bash
npm start
```

콘솔에 `✅ 로그인 완료`가 뜨면 정상 작동 중입니다. 이제 음성채널에 입장/퇴장하면 봇이 자동으로 따라 들어와서 안내 음성을 재생합니다.

## 참고 사항

- TTS는 마이크로소프트 엣지의 무료 음성 엔진(`msedge-tts` 패키지)을 사용하며 인터넷 연결이 필요합니다.
- **말하기 속도와 목소리는 `index.js` 맨 위쪽에서 바꿀 수 있습니다:**
  ```js
  const TTS_VOICE = 'ko-KR-InJoonNeural'; // 남자 목소리. 여자 목소리는 'ko-KR-SunHiNeural'
  const TTS_RATE = '+25%'; // 말하기 속도. '+0%'가 기본, '+50%'면 훨씬 빠름, '-20%'면 느리게
  ```
  값을 바꾼 뒤 봇을 재시작(`Ctrl+C` 후 `npm start`)하면 바로 적용됩니다.
- 오디오 인코딩은 `opusscript`(순수 JS)를 사용해서 별도 컴파일 도구 없이 `npm install`만으로 어떤 환경에서도 설치가 잘 됩니다.
- 여러 명이 동시에 들어오고 나가도 순서대로 큐에 쌓여서 재생되므로 음성이 겹치지 않습니다.
- 안내가 다 끝나면 3초 후 봇이 자동으로 채널을 나갑니다 (`LEAVE_DELAY_MS` 값으로 조절 가능).
- 봇을 다른 서버에서도 쓰려면 그냥 같은 봇을 여러 서버에 초대하면 됩니다 (길드별로 독립적으로 동작).
- 안내 문구를 바꾸고 싶으면 `index.js`의 `speak(...)` 호출 부분 문자열만 수정하면 됩니다.

## 문제 해결

- **소리가 안 나요**: 봇에게 `Speak` 권한이 있는지, 채널에 인원 제한이 걸려있지 않은지 확인하세요.
- **연결 오류(음성 채널 연결 실패)**: `libsodium-wrappers` 설치가 잘 됐는지 확인하세요 (`npm install`이 정상 종료됐는지).
- **봇이 계속 채널을 옮겨다녀요**: 여러 채널에서 동시에 입퇴장이 발생하면 마지막 이벤트의 채널로 이동합니다. 필요하면 채널을 고정하는 로직을 추가할 수 있습니다.
